# Code of Conduct

Local Agent Stack welcomes people with different backgrounds, identities and
levels of experience. Be respectful, assume good faith, discuss ideas rather
than people, and give clear technical feedback without harassment or insults.

Unacceptable behavior includes discrimination, threats, sexual attention,
doxxing, sustained disruption, and publishing another person's private
information. This standard applies in repository discussions, reviews, project
events and other spaces where someone represents the project.

Maintainers may edit or remove contributions, temporarily limit participation,
or permanently ban participants whose behavior harms the community. Decisions
should be proportionate, documented privately when appropriate, and applied
consistently.

Report conduct concerns privately to the repository owners through GitHub. Do
not open a public issue containing sensitive personal information. Maintainers
will protect the reporter's privacy as far as reasonably possible and will not
retaliate against good-faith reports.
